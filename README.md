# Site for my Minecraft Modpack.

I am currently trying to make the largest Minecraft Forge 1.20.1 Modpack, so I made a site to document my progress, showcase screenshots, and more!

You can try out the site [here](https://spheroidon.github.io/personal-site/)!

The modpack itself is currently unavailable but will be released once I beat the goal and get to 2000 mods.

### Site Features:
- Navbar with links dynamically generated from a dict!
- Image gallery dynamically generated from a dict!
- Captions for images!
- Clicking on images opens a lightbox!
- You can see what mods were featured in the screenshot from the lightbox!
- Changelog section dynamically generated from a dict!
